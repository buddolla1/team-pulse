# Frontend Documentation

This folder contains the frontend documentation for the BSL employee billing and management portal.

## Contents

- [Application Overview](./application.md)
- [Components Guide](./components.md)
- [Pages and Routes](./pages.md)
- [Redux State Management](./redux.md)

## Scope

The frontend is a React 18 application built with React Router, Redux Toolkit, PrimeReact, Material UI, and a shared API service layer.

The documentation focuses on:

- application structure
- component organization
- page and route responsibilities
- Redux store design and async data flow
